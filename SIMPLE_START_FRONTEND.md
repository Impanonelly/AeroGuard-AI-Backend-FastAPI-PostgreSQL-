# 🚀 Simple Way to Start Frontend

## ✅ Node.js is Installed - Good!

Now let's start the frontend server properly.

---

## 🎯 Easiest Method: Use the Batch File

### Step 1: Open File Explorer
1. Press `Windows Key + E`
2. Navigate to: `E:\Study material\Sem 6\Final Year Project\aeroguard_frontend`

### Step 2: Double-Click the Batch File
1. Find: `start_frontend.bat`
2. **Double-click it**
3. A command window will open
4. **Wait for**: "Local: http://localhost:3000/"
5. **Keep the window open!**

---

## 🖥️ OR Use VS Code Terminal

### Step 1: Open NEW Terminal
- Click **"+"** button next to terminal tab
- Make sure it's a **NEW** terminal (not the backend one)

### Step 2: Copy and Paste These Commands
```powershell
cd "E:\Study material\Sem 6\Final Year Project\aeroguard_frontend"
npm run dev
```

**Press Enter after each command.**

---

## ✅ What Success Looks Like

After running `npm run dev`, you should see:

```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

**If you see this, the server is running!** ✅

---

## 🌐 Then Open Browser

1. **Open browser**
2. **Type**: `http://localhost:3000`
3. **Press Enter**
4. **You should see**: AeroGuard AI Login page!

---

## ⚠️ Important

- **Keep the terminal/window open** - Closing it stops the server
- **You need 2 things running**:
  - Backend (port 8000) ✅ You have this
  - Frontend (port 3000) ← Start this now!
