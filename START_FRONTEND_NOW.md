# 🚀 Start Frontend - Quick Steps

## ✅ Node.js is Installed - Perfect!

Now let's start the frontend:

---

## 📋 Step-by-Step

### Step 1: Open New Terminal in VS Code
1. In VS Code, look at the bottom where your terminal is
2. **Click the "+" button** next to the terminal tab
   - This opens a **new terminal** (you can have multiple terminals open)
3. You should see a new terminal tab

### Step 2: Navigate to Frontend Directory
In the **new terminal**, type:
```powershell
cd "E:\Study material\Sem 6\Final Year Project\aeroguard_frontend"
```

### Step 3: Install Dependencies (First Time Only)
```powershell
npm install
```

**This will take 2-3 minutes** - it's downloading all React packages.

**You should see:**
```
added 200+ packages
```

### Step 4: Start Frontend Server
```powershell
npm run dev
```

**You should see:**
```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

---

## ✅ Success!

Once you see "Local: http://localhost:3000/", your frontend is running!

---

## 🌐 Open in Browser

1. Open your browser
2. Go to: **http://localhost:3000**
3. You should see the **AeroGuard AI Login page**!
